# 词光 Word Atlas · 安卓原生版

[![Build APK](https://github.com/zhq734/words-atlas-apk/actions/workflows/build.yml/badge.svg)](https://github.com/zhq734/words-atlas-apk/actions/workflows/build.yml)

把 [0xlei.tech/words](https://0xlei.tech/words/)（词光 · 雅思词汇图鉴）做成的**原生 Android 应用**：界面完全用 Android 控件实现，直接消费官网的静态数据与媒体资源，而不是套一层 WebView。

## 功能

五个标签页，覆盖站点全部能力：

| 模块 | 内容 |
| --- | --- |
| **今日** | 问候语与日期、今日学习卡（新词 / 待复习）、开始学习与复习、连续打卡与已学统计、最近学习列表 |
| **图鉴** | 7298 词网格卡片；难度（A1–C2）、话题、学习状态三组筛选；中英文搜索；收藏夹 |
| **书房** | 《小王子》27 章目录、章节插图、中英双语段落、点击段落朗读、上一章 / 下一章 |
| **练习** | 易混词辨析 226 组（要点 / 例句 / 填空小测）、同义替换 3185 题（十题一轮）、阅读判断 732 篇（T/F/NG 判断题）；同义替换与阅读正文每段可点击整段朗读 |
| **我的** | 学习统计（点数字查看已学 / 较熟悉 / 收藏的单词列表，点词进入详情；点连续打卡打开打卡日历）、外观（深 / 浅）、发音口音、每日新词数、学习起点、考试日期、插画风格、导出 / 导入学习数据、清空记录 |

其他原生能力：

- **词条详情**：进入即自动朗读一遍单词，大插画、英 / 美音标与发音、义项中英对照、双语例句（逐句朗读、逐词可点）、常用搭配、词族、近反义词、记忆提示；底部「认识 / 不认识」从学习队列进入时直接记录并回到学习页切下一词，从图鉴、阅读等其他入口进入时只记录不退出
- **学习流程**：认识 / 不认识标记，间隔重复复习队列（1、2、4、7、15、30 天），本轮结算页；每张新词卡出现时自动播放一遍标准读音
- **阅读高亮**：正文生词可点击直接跳词条
- **练习朗读**：同义替换的原句 / 改写句、阅读判断的每一段正文都支持点击整段朗读（点文字或右侧喇叭图标均可，Edge TTS 合成，与书房段落一致）；阅读正文里点生词仍是跳转词条，点其余位置才朗读
- **学习明细**：「我的」页四个统计块均可点击——已学、较熟悉、收藏分别打开对应单词列表（已学 / 较熟悉按最近学习时间倒序，收藏按收藏先后倒序），点任意单词进入完整词条；连续打卡打开打卡日历，有学习记录的日期画红圈，可逐月翻看，底部显示连续打卡与本月天数；没有记录时显示对应空态提示
- **深浅主题**：所有界面、系统栏、弹窗都跟随主题切换
- **发音三级兜底**：单词优先播放官网预录 mp3，缺失或加载失败时用 Edge TTS 在线合成，再失败退回系统语音合成；离线时也能读
- **例句朗读**：官网只提供单词音频，例句用 Edge TTS 现场合成（英音 / 美音跟随设置，音色分别为 en-GB-SoniaNeural / en-US-JennyNeural，与参考项目 translation 一致），合成结果按文本缓存，重听不再联网；失败退回系统语音合成
- **例句查词**：例句里每个单词下方都带强调色下划线，一眼可见可点击；点开弹出音标与中文释义并立即朗读；复数、过去式、进行时等变形自动还原到原形，未收录的词也能听发音，收录的词可跳完整词条

## 数据策略

站点本身是纯静态 SPA，没有后端接口；所谓「接口」就是一组 JSON 与媒体文件。应用按下面的方式消费它们：

- **内置 + 自动更新**：`atlas/index.json`、词条分片、易混词、同义替换、阅读索引、全书章节等 JSON 全部打包进 APK（约 15MB 原始数据，压缩后 APK 5.5MB），**离线可用**；启动时比对官网 `index.json` 的 `version`，变大则重新下载并写入私有目录覆盖。
- **按需拉取并缓存**：插画（`atlas/img`、`atlas/thumb`、`atlas/classic/img`）、发音（`atlas/audio/{uk,us}`）、阅读正文（`atlas/extras/readings/<id>.json`）在首次使用时从官网下载，内存 LRU + 磁盘缓存双级缓存，之后离线可看。
- **例句语音现场合成**：官网没有例句音频，改用微软 Edge 朗读接口（与开源项目 edge-tts 相同的协议，`Sec-MS-GEC` v2 鉴权在本地计算）合成 mp3，按「音色 + 文本」缓存到应用私有目录（`cache/tts2`，旧目录 `cache/tts` 启动后自动清除），缓存超过 200 条自动淘汰旧文件。
- **本地进度**：学习进度、收藏、设置与逐日打卡历史存放在 SharedPreferences（内存缓存加速），可导出为 JSON 文本备份与恢复。

```
app/src/main/assets/words/        内置词库与站点静态资源
app/src/main/java/tech/lei/wordatlas/
├── data/
│   ├── Repo.java                 数据仓库：assets/filesDir 双层读取、下载、更新检查
│   ├── Models.java               数据模型
│   ├── Store.java                学习进度 / 收藏 / 设置（SharedPreferences + 内存缓存）
│   ├── Media.java                图片与音频加载：LRU + 磁盘缓存 + 线程池
│   ├── EdgeTts.java              Edge TTS 合成：Sec-MS-GEC v2 鉴权 + 原生 WebSocket 客户端
│   ├── Voice.java                发音入口：官网音频 → Edge TTS → 系统 TTS
│   └── Speech.java               系统语音合成兜底（TextToSpeech）
└── ui/
    ├── MainActivity.java         五标签框架（页面常驻，切换不丢状态）
    ├── TodayPage / AtlasPage / BooksPage / PracticePage / MePage.java
    ├── WordDetailActivity / LearnActivity / BookReaderActivity.java
    ├── ConfusableActivity / ParaphraseActivity / ReadingActivity.java
    ├── WordListActivity.java     已学 / 较熟悉 / 收藏单词列表（从「我的」统计进入）
    ├── Lookup.java               例句点词：链接化与释义弹窗
    └── Theme.java                颜色、圆角、字号与系统栏主题
tools/fetch_site.py               重新抓取站点静态资源
tools/gradle/gradle-8.11.1/       构建用 Gradle
build.sh                          一键构建 debug 包
```

## 构建

前置：JDK 17、Android SDK（platform 35 / build-tools 35.0.0）。

仓库自带 Gradle Wrapper，克隆后直接构建：

```bash
./gradlew :app:assembleRelease   # release 包（debug 签名，可直接安装）
./gradlew :app:assembleDebug     # debug 包
./build.sh                       # debug 包（使用 tools/gradle 本地分发）
```

`build.sh` 依赖的本地 Gradle 分发（约 145 MB）不在仓库内，需要时把 `gradle-8.11.1` 解压到 `tools/gradle/`。

## 持续集成

`.github/workflows/build.yml` 在推送到 `main`、提交 PR 和手动触发时，用 JDK 17 构建 release 与 debug 两个 APK，并以 `word-atlas-apk` 制品上传，可在 Actions 运行页下载；推送 `v*` 标签时还会额外创建 GitHub Release 并附上 APK。

```bash
gh workflow run build.yml                  # 手动触发
git tag v2.0.7 && git push origin v2.0.7   # 打标签发版
```

产物：

| 文件 | 大小 | 说明 |
| --- | --- | --- |
| `词光-v2.0.7.apk` | 5.5 MB | release 版，debug 签名，可直接安装 |
| `词光-v2.0.7-debug.apk` | 6.5 MB | debug 版，可远程调试 |

- 包名 `tech.lei.wordatlas`，minSdk 24（Android 7.0），targetSdk 35
- 唯一第三方依赖：`androidx.recyclerview:recyclerview:1.3.2`，其余全部用系统控件与 `org.json`

安装：

```bash
adb install -r 词光-v2.0.7.apk
```

## 已验证

在 Android 15（API 35）arm64 模拟器上逐页实测通过：

- 首页统计与最近学习、图鉴 7298 词网格 + 图片加载 + 搜索 + 收藏筛选
- 词条详情（插画 / 音标 / 发音 / 释义 / 例句 / 搭配）、收藏、认识与不认识记录
- 学习流程完整一轮 10 词并结算；复习队列空态
- 书房 27 章目录、章节插图、双语正文、上下章切换
- 易混词列表与详情（词条目 / 辨析要点 / 例句 / 小测判分）
- 同义替换一轮 10 题答题与结果页；阅读判断正文加载、生词高亮跳转、T/F/NG 判分
- 深浅主题切换（含系统栏图标、弹窗）、经典线稿插画切换、数据导出到剪贴板与导入恢复
- 例句朗读：Edge TTS 现场合成 24kHz mp3（首条约 3 秒出声），同一句重复点击命中缓存秒开；系统语音合成作为兜底；合成音频与直连服务端逐样本一致（0.0–3.1 秒相关系数 ≈1.000），无破音
- 词条详情自动朗读：从图鉴 / 阅读 / 易混词任一处进入词条页，加载完成即自动播放一遍标准发音
- 详情页认识 / 不认识联动：学习页点「查看完整词条」进入后，在详情页点认识或不认识会直接回到学习页并切到下一词（计数器 1/10 → 2/10 → 3/10 实测）；按返回键退出则不推进，队列保持不变；从图鉴搜索进入时点认识只记录并停留在详情页
- 语音缓存升级隔离：旧版缓存目录 `tts` 在首次触发语音时整体删除，避免继续播放旧实现生成的损坏音频
- 例句点词：词条详情 / 学习卡片 / 易混词三处均可点击单词，每个单词下方有强调色下划线提示可点，弹窗显示音标、难度、释义与原形，自动朗读；变形词（borrowed → borrow、bored → bore）正确还原，未收录词仍可发音；深色与浅色主题下划线均清晰可辨
- 单词发音三级兜底、学习新词自动播放读音、书房段落点击朗读
- 练习段落朗读：同义替换原句与改写句点击文字或喇叭分别播放（230976 / 243648 帧实测）、阅读判断正文每段点击播放（486720 帧 ≈ 20 秒）、点生词仍跳词条而不触发朗读、离开页面自动停止
- 「我的」统计详情：已学 13 个（按最近学习倒序）、较熟悉（掌握等级 ≥ 3，实测当分钟词升到 3 级后出现在列表）、收藏（最近收藏在前）三个列表均可点词进入完整词条；无记录时显示空态；在详情页收藏后返回，统计数字立即刷新
- 打卡日历：本月已打卡日期画红圈（11/1、11/3、11/4 实测），翻到上一月可看到跨月记录（10/28），当前月时下一月按钮自动禁用；底部显示「连续打卡 N 天 · 本月 M 天」；深浅主题下红圈与文字均清晰
- 打卡历史：旧版本只保存最后打卡日与连续天数，升级后按连续天数向前反推补出历史并立即落盘；导出备份包含 `checkins`，导入可恢复
- 返回 / 收藏 / 音量 / 关闭 / 行尾箭头全部为 Material 矢量图标，深浅主题自动着色
